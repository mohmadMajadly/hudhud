Claude Code option schema (`@hudhudjs/claude-code/schemas/options.schema.json`): strict JSON Schema of the connect and session options, generated from the TypeBox sources with precompiled validators and no run-time schema dependency. The adapter's protocol machines, option resolution, argv and environment builders land internally and are exported with `connect` and `session` in a later wave.
