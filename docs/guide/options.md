# Options reference

Options are validated strictly before anything runs: unknown keys are refused at every level, values must be plain JSON (except `signal`, `onPermission` and `events.signal`), strings may not contain NUL characters, and cross-field rules apply. Every failure is an `InvalidOptionsError` (`INVALID_OPTIONS`) with `details.path` and `details.rule`, except `workspaceTrust: 'context'` and `backend: 'agent-sdk'`, which are `CAPABILITY_UNSUPPORTED`. A property set to `undefined` counts as absent.

- `connect(options)` takes the [connect options](#connect-options).
- `harness.sessions.create(options)` takes the [session options](#session-options); `harness.sessions.resume(id, options)` also takes `fork`.
- `session(options)` takes both in one object; the `claudeCode` options of both are merged into one `claudeCode` object.

The "Posture" column says whether the option appears in the [security posture](security.md#security-posture).

## Connect options

| Option                                          | Type                                    | Default               | Posture            | Meaning                                                                                                                         |
| ----------------------------------------------- | --------------------------------------- | --------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `backend`                                       | `'native'`                              | `'native'`            | no                 | The only backend in v1                                                                                                          |
| `binaryPath`                                    | string                                  | discovery             | no                 | The Claude Code binary to use; nothing else is tried ([Getting started](getting-started.md#where-hudhud-looks-for-claude-code)) |
| `binaryVerification`                            | `'advisory'` \| `'strict'`              | `'advisory'`          | yes                | [Binary verification](security.md#binary-verification)                                                                          |
| `signal`                                        | `AbortSignal`                           | none                  | no                 | Aborts `connect` (`ABORTED`)                                                                                                    |
| `claudeCode.configDir`                          | string                                  | the user's config dir | yes (`'isolated'`) | Claude Code's config directory (`CLAUDE_CONFIG_DIR`)                                                                            |
| `claudeCode.bare`                               | boolean                                 | `false`               | yes                | Passes `--bare`                                                                                                                 |
| `claudeCode.binaryDigests`                      | `{ [version]: { [platform]: sha256 } }` | none                  | no                 | Extra trusted digests, for example `{ '2.1.296': { 'linux-arm64': '<64 hex>' } }`                                               |
| `claudeCode.dangerouslyAllowRawControl`         | boolean                                 | `false`               | yes                | Allows raw control requests and frames ([The raw tier](raw.md))                                                                 |
| `claudeCode.dangerouslyAllowKnownBrokenVersion` | boolean                                 | `false`               | yes                | Runs a version listed as known broken instead of refusing it ([Compatibility](compatibility.md))                                |

## Session options

| Option                               | Type                                      | Default                               | Posture                     | Meaning                                                                                                                  |
| ------------------------------------ | ----------------------------------------- | ------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `cwd`                                | string                                    | `process.cwd()`                       | no                          | The working directory; resolved to its real path and checked before start (`CWD_INVALID`, and on Windows `CWD_TOO_LONG`) |
| `permissionMode`                     | `PermissionMode`                          | `'default'`                           | yes                         | [Permission modes](permissions.md#permission-modes)                                                                      |
| `dangerouslyAllowBypassPermissions`  | boolean                                   | `false`                               | yes                         | Required for `'bypassPermissions'`, initially or through `setPermissionMode`                                             |
| `onPermission`                       | `PermissionHandler`                       | none                                  | yes (`permissionPrompting`) | [The permission handler](permissions.md#the-permission-handler)                                                          |
| `workspaceTrust`                     | `'none'` \| `'context'` \| `'full'`       | `'none'`                              | yes                         | [Workspace trust](security.md#workspace-trust); `'context'` is unsupported                                               |
| `projectCredentialEnv`               | `'refuse'` \| `'allow'`                   | `'refuse'` when project settings load | yes                         | [The project credential guard](security.md#the-project-credential-guard); only valid when project settings load          |
| `env`                                | `EnvOption`                               | `'harness'`                           | yes                         | [The environment](security.md#the-environment)                                                                           |
| `autoUpdate`                         | `'disabled'` \| `'harness-default'`       | `'disabled'`                          | yes                         | `DISABLE_AUTOUPDATER=1` unless `'harness-default'`                                                                       |
| `nonessentialTraffic`                | `'disabled'` \| `'harness-default'`       | `'disabled'`                          | yes                         | `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` unless `'harness-default'`                                                  |
| `dangerouslyAllowConfigWrites`       | boolean                                   | `false`                               | yes                         | Keeps permission updates that write settings files                                                                       |
| `onAuthFailure`                      | `'fail-fast'` \| `'harness-retry'`        | `'fail-fast'`                         | no                          | [Authentication failures](security.md#authentication-failures)                                                           |
| `onOversizedFrame`                   | `'fail'` \| `'skip'`                      | `'fail'`                              | no                          | [Frame limits](security.md#frame-limits)                                                                                 |
| `maxFrameBytes`                      | integer, 1 MiB to 1 GiB                   | 67 108 864 (64 MiB)                   | no                          | Largest output line                                                                                                      |
| `maxOutboundFrameBytes`              | integer, 1 MiB to 1 GiB                   | 33 554 432 (32 MiB)                   | no                          | Largest write to Claude Code                                                                                             |
| `firstFrameTimeoutMs`                | integer, 1 000 to 86 400 000              | 60 000                                | no                          | Handshake deadline (`HANDSHAKE_TIMEOUT`)                                                                                 |
| `idleStallMs`                        | integer, 1 000 to 86 400 000              | 300 000                               | no                          | Silence before a `stalled` event                                                                                         |
| `closeTimeoutMs`                     | integer, 1 000 to 86 400 000              | 30 000                                | no                          | Deadline of `close()`, from the call                                                                                     |
| `termination.interruptWaitMs`        | integer, 1 000 to 86 400 000              | 1 000                                 | no                          | [Abort ladder](sessions.md#abort-and-dispose): wait for the interrupt answer                                             |
| `termination.eofGraceMs`             | integer, 1 000 to 86 400 000              | 2 000                                 | no                          | Wait after end of input                                                                                                  |
| `termination.termGraceMs`            | integer, 1 000 to 86 400 000              | 5 000                                 | no                          | Linux and macOS: wait after `SIGTERM`                                                                                    |
| `termination.taskkillGraceMs`        | integer, 1 000 to 86 400 000              | 2 000                                 | no                          | Windows without a job: wait after `taskkill`                                                                             |
| `trace`                              | `{ traceparent, tracestate? }`            | none                                  | no                          | [Tracing](diagnostics.md#tracing); `traceparent` in W3C format                                                           |
| `events`                             | `SubscriberOptions`                       | 10 000 events, 64 MiB, `'error'`      | no                          | Defaults for this session's subscribers ([Events](events.md#bounded-queues-and-overflow))                                |
| `signal`                             | `AbortSignal`                             | none                                  | no                          | Aborts the start of the session only                                                                                     |
| `claudeCode.settingSources`          | array of `'user'`, `'project'`, `'local'` | from `workspaceTrust`                 | yes                         | Instead of `workspaceTrust`; not both                                                                                    |
| `claudeCode.model`                   | string                                    | Claude Code's default                 | no                          | `--model`                                                                                                                |
| `claudeCode.allowedTools`            | array of rule strings                     | none                                  | yes                         | `--allowed-tools` ([Tool rules](permissions.md#tool-rules))                                                              |
| `claudeCode.disallowedTools`         | array of rule strings                     | none                                  | yes                         | `--disallowed-tools`                                                                                                     |
| `claudeCode.additionalDirectories`   | array of strings                          | none                                  | yes                         | One `--add-dir` each                                                                                                     |
| `claudeCode.maxTurns`                | integer, at least 1                       | none                                  | no                          | `--max-turns`; a turn that hits it ends with outcome `'max-turns'`                                                       |
| `claudeCode.includePartialMessages`  | boolean                                   | `false`                               | no                          | Streams `message.delta` events                                                                                           |
| `claudeCode.appendSystemPrompt`      | string                                    | none                                  | no                          | Appended to Claude Code's system prompt                                                                                  |
| `claudeCode.backgroundWaitCeilingMs` | integer, 1 000 to 86 400 000              | 600 000                               | no                          | How long Claude Code waits for background tasks after its input ended (`CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS`)           |

`sessions.resume(id, options)` also takes `fork: boolean` (default `false`); see [Resume and fork](sessions.md#resume-and-fork).

## Cross-field rules

| Rule (`details.rule`)    | Refused                                                                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `trust-and-sources`      | `workspaceTrust` and `claudeCode.settingSources` both set                                                                                       |
| `bypass-permissions`     | `permissionMode: 'bypassPermissions'` without `dangerouslyAllowBypassPermissions: true`                                                         |
| `project-credential-env` | `projectCredentialEnv` set while the sources include neither `project` nor `local`                                                              |
| `tool-rule`              | A tool rule that Claude Code would split or misread ([Tool rules](permissions.md#tool-rules))                                                   |
| `env-pinned`             | `env` naming a variable hudhud sets itself ([The environment](security.md#the-environment))                                                     |
| `env-duplicate`          | On Windows, two `env` names that differ only in letter case                                                                                     |
| `session-id`             | A `resume` id that is not a UUID                                                                                                                |
| `command-line-too-long`  | On Windows, a Claude Code command line above 32 000 UTF-16 code units (shorten `appendSystemPrompt`, `additionalDirectories` or the tool rules) |
| `spawn-spec`             | An environment that cannot start a process, for example an explicit `env` map without `SYSTEMROOT` on Windows                                   |
| `schema`                 | An unknown key, a wrong type, or a value outside its range (`details.keyword` names the JSON Schema keyword)                                    |

The JSON Schema of the options ships in the package as `schemas/options.schema.json`; import it as `@hudhudjs/claude-code/schemas/options.schema` (the `exports` map adds the `.json`), with an import attribute `{ type: 'json' }`.
