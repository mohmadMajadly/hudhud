# hudhud v1 release checklist

Status: 2026-10-16, written by W7-T4 on main f2236d2 plus the W7-T4 branch; updated 2026-10-17 by W7-Z on the closer branch (all Wave 7 branches merged; items 1.10, 1.11 and 3.7 to 3.9 added). This is the list of every gate between the current tree and the first npm publish of `hudhudjs`, `@hudhudjs/core`, `@hudhudjs/claude-code` and `@hudhudjs/win32-job-x64`. Each gate says who acts, how it is verified and what state it is in today. A gate is closed only by its verification, never by a statement.

Who acts:

- **Owner**: only the repository owner can do it (npm account, GitHub settings, legal decisions). The agents prepare it, the owner does it.
- **Lead**: the lead dispatches, merges and decides.
- **Agent**: work an agent does on a branch, merged by the lead.

States: **done** (verified, evidence cited), **open** (work left), **owner** (waits for an owner action), **decision** (waits for a lead or owner ruling).
