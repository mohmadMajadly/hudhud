# hudhud v1 release checklist

Status: 2026-10-16, written by W7-T4 on main f2236d2 plus the W7-T4 branch; updated 2026-10-17 by W7-Z on the closer branch (all Wave 7 branches merged; items 1.10, 1.11 and 3.7 to 3.9 added); updated 2026-10-17 by FX-D of the pre-release review fixes on main 313b68b (states of 1.1, 1.4, 1.5, 1.7 and 3.3 from the CI runs; items 1.13, 2.5, 3.10 to 3.12 and 4.10 to 4.12 added; 4.3, 4.4 and 4.8 restated). This is the list of every gate between the current tree and the first npm publish of `hudhudjs`, `@hudhudjs/core`, `@hudhudjs/claude-code` and `@hudhudjs/win32-job-x64`. Each gate says who acts, how it is verified and what state it is in today. A gate is closed only by its verification, never by a statement.

Who acts:

- **Owner**: only the repository owner can do it (npm account, GitHub settings, legal decisions). The agents prepare it, the owner does it.
- **Lead**: the lead dispatches, merges and decides.
- **Agent**: work an agent does on a branch, merged by the lead.

States: **done** (verified, evidence cited), **open** (work left), **owner** (waits for an owner action), **decision** (waits for a lead or owner ruling).
