# Security policy

hudhud is pre-alpha and the repository is private. There are no releases, so no version is supported yet.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

While the repository is private, report directly to the repository owner. When the repository becomes public, reports will go through GitHub private vulnerability reporting ("Report a vulnerability" on the Security tab), and this file will be updated with the supported versions, the expected response time and the disclosure process before that happens.

## Scope

The threat model is in [docs/architecture.md](docs/architecture.md#security-model-and-threat-model) and [ADR-0012](docs/adr/0012-security-defaults-and-trust.md).
